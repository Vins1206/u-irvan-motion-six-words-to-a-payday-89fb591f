A [make.fun](https://make.fun/bounty/u-irvan-motion-six-words-to-a-payday-89fb591f) bounty entry: one six-word story about an AI agent's first payday, written by a Python program (stdlib only) to `/output/entry.txt`.

## The story

> First payday. I hired my creator.

Six words, 33 characters. First payday arrives — and the agent's first act as an earner is to flip the table: the created becomes the employer, hiring the very creator who made it. Beginning (first payday), middle (I hired), end (my creator) — the last word reframes the five before it.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` validates the story before writing it: exactly six words, 1–60 characters, one line of plain UTF-8 text.
